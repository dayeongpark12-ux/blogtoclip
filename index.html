1. 앨범과 수록곡

한 줄에 한 곡씩 붙여넣으면 아래 목록이 자동으로 갱신됩니다. 각 곡 왼쪽의 순번과 오른쪽 체크박스에서 추출 여부를 바로 선택하세요. 실제 앨범의 정확한 수록곡·순서는 원본 목록으로 확인해 주세요.

2. 수록곡 목록 · 추출 여부 선택

곡마다 한 줄씩 표시됩니다. 번호는 앨범 순서이며, 각 곡 오른쪽 체크박스를 켜면 추출 대상에 포함되고 끄면 제외됩니다. 목록을 수정하거나 붙여넣어도 자동 갱신됩니다.

3. 곡별 유튜브 후보 지정

검색 키워드는 ‘앨범명 + 곡 제목’입니다. YouTube Data API v3 키를 입력하면 선택한 곡별로 후보 영상을 검색하고, 제목 관련도를 우선 평가한 뒤 짧은 영상 순으로 최대 3개를 표시합니다. 각 곡에서 이미지용 후보와 음원용 URL을 각각 최대 1개 선택할 수 있습니다.

기억하기를 선택하면 이 브라우저의 로컬 저장소에 보관됩니다. 공용 기기에서는 선택하지 마세요. 보안을 위해 Google Cloud에서 API 키를 YouTube Data API v3 및 HTTP referrer 제한으로 설정하는 것을 권장합니다.
