앨범 썸네일 정리 도구

앨범 검색 자동 수록곡 입력 · 곡별 유튜브 후보 탐색 · 2열 4행 송북 출력

1. 앨범과 수록곡

검색 버튼을 누르면 앨범의 전체 수록곡이 여기에 자동으로 입력됩니다. 직접 편집도 가능합니다.

2. 수록곡 목록 · 추출 여부 선택

새로 가져온 곡은 기본적으로 모두 추출(선택) 상태로 활성화됩니다.

3. 곡별 유튜브 후보 지정

API 키를 입력 후 검색하면 큼직한 썸네일과 함께 후보가 표시됩니다. 하단의 '추가 후보 3개 더 보기' 버튼으로 후보를 더 탐색할 수 있습니다.
